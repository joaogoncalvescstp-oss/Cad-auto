# AI agent instructions

All AI assistants (Claude, Copilot, Codex, Cursor, …) follow the same rules.
They live in [`CLAUDE.md`](CLAUDE.md) — read it before making any change.

Short version:

1. Bump the space emoji badge on every push (`python3 tools/bump_space.py "note"`).
2. Keep `main` in sync with the working branch.
3. Stick to the FBK-style navy/gold design system (`wiki/Design-System.md`).
4. Verify the inline script parses before pushing.
